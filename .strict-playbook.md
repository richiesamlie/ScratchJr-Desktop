# strictNullChecks burn-down playbook (ScratchJr)

The repo just enabled `strictNullChecks` in tsconfig.json. Your job: drive
`npx tsc --noEmit` errors in YOUR assigned files to zero, using ONLY the
patterns below. Do not touch other files, do not change tsconfig, do not run
the test suite or build.

## Golden rules

1. **ZERO behavior change.** Every fix is a type annotation, a `!`
   (non-null assertion — no runtime effect), an `as Element`/`as HTMLElement`
   cast, a `String(...)`/`Number(...)` wrapper, `??`/`||` fallback, or
   `= null` in place of `= undefined`. Never reorder logic, never add/remove
   runtime branches, never change values passed to DOM APIs in a way that
   alters the coerced string.
2. `!` is a compile-time assertion — it never runs. Prefer it for "this is
   statically known to exist" (static DOM lookups, event params that callers
   always pass).
3. When the code already null-checks (`if (!x) return;` / `if (x) {`), the
   narrowing works — DON'T add `!` there; only fix what tsc flags.
4. `as Element` / `as HTMLElement` / `as HTMLCanvasElement` are fine for DOM
   nodes (well-known DOM casts). Do NOT introduce `any` anywhere.

## Pattern catalog (in order of frequency)

### A. `var x = []` now infers `never[]` (TS 7) — every push/read errors
`var res = [];` → `var res: <ElementType>[] = [];`
Pick the element type from what is pushed/read:
- `res.push(p.childNodes[i])`, `res[i].getAttribute(...)` → `Element[]` or `HTMLElement[]`
- `res.push(points.getItem(i))`, `res[0].x` → `Point[]` (import `type {Point}` from `../geom/Vector` or `../../geom/Vector`)
- `res.push(['L', x, y])`, `res[0][1]` → `(string | number)[][]`
- `res.push({cmd, pt})` → `Array<{cmd: string; pt: Point}>`
- module-level `let dragGroup = []` → `let dragGroup: Element[] = []`
Also `var d = [['M', ...]]` → `var d: string | (string | number)[][] = [...]`.

### B. `let x = undefined;` → `let x: T | null = null;`
Module-level state (`let currentShape = undefined` → `let currentShape: Element | null = null;`,
`let target = undefined` → `let target: Element | null = null;`).
Then every `x = undefined;` elsewhere in the file → `x = null;`, and null-flagged
uses (`x.getAttribute(...)` when `x` wasn't narrowed) get `x!` or an existing
`if (x)` guard handles them.

### C. `gn(...)` possibly-null
`gn('id')` returns `HTMLElement | null`. If tsc flags a gn() result, add `!`:
`gn('id')!`. Skip if the code already null-checks it (`if (!gn(x))` / `var y = gn(x); if (!y)`).

### D. `.parentNode` / `.firstChild` / `.querySelector(...)` possibly null
- `g.parentNode.removeChild(g)` → `g.parentNode!.removeChild(g)`
- if the result needs `.tagName`/`.id` (Element-only), cast: `(el.parentNode as Element).tagName`
- `document.getElementById('layer1')!.parentNode!` etc.

### E. `getContext('2d')` possibly null → `!`
`var ctx = cnv.getContext('2d');` → `cnv.getContext('2d')!`.

### F. `getAttribute(...)` returns `string | null`
- passed to a string param (`indexOf(...)`, `setAttribute`) → `!` at the call
  (`indexOf(el.getAttribute('x')!)`) — runtime identical (null coerces as before)
- used in arithmetic (`getAttribute('r') * 1.5`) → wrap: `Number(el.getAttribute('r')!) * 1.5`
- assigned to a `string`-typed field → `el.getAttribute('x')!`
- `setAttribute('opacity', 0.6)` / numeric attrs → `String(0.6)` (never change the value, only stringify)

### G. optional params `static foo (e?)` used without check
`e.preventDefault()` with `e?` → `e!.preventDefault()` (callers always pass it).

### H. `window.onmousemove = undefined;` etc. → `= null;`
(Window handler props are `((...)=>any) | null`.)

### I. element `childNodes[i]` needing DOM methods
`kid.getAttribute(...)` where `kid` is a `ChildNode` → `(kid as HTMLElement).getAttribute(...)` —
cast once into a named const when used multiple times: `const kidEl = kid as HTMLElement;`.

### J. comparisons / coercions
- `el.getAttribute('stroke-width') == Paint.strokewidth` (string vs number) →
  `== String(Paint.strokewidth)` (preserves JS coercion semantics)
- `'fill': c` where `c` is `string | null` into a `Record<string, string|number>` →
  `'fill': String(c)` (setAttribute coerced null to "null" before — String(null) does the same)

## Verify

After each fix run: `npx tsc --noEmit 2>&1 | grep -E "<yourfile>"` — the goal is
zero lines for YOUR files. Other files may still error — that's fine, don't
touch them. `git diff` to confirm every hunk is type-only.
