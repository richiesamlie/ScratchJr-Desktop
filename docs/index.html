ScratchJr Reborn

A modernized desktop port of ScratchJr for Windows, macOS, and Linux — with more room to create, a hardened sandbox, and a fully strict, tested codebase.

Download the latest release

Screenshots

Why Reborn?

  • More room to create — 8 pages by default (configurable), a scrollable page strip, a bigger character sidebar, and + buttons that never disappear
  • Scrolling that just works — native mouse-wheel scrolling with a scrollbar that matches your position
  • Safe by design — sandboxed renderer, content security policy, SQL injection guards, a narrow preload bridge
  • Modern stack — Electron 42, Node 22/26, an esbuild-bundled renderer, fully async IPC
  • Trustworthy codebase — all 56 renderer files in strict TypeScript with zero errors and zero any, 98 tests including a jsdom harness for the project file format
  • Reliable releases — all six platforms built natively with SHA256 checksums
